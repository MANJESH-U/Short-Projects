This repository contains 10 Python projects demonstrating skills in **Random Forest, NumPy, Matplotlib, data analysis, machine learning, and data visualization**. Each project is designed to be fully reproducible and beginner-friendly.

---

## **Projects**

### 1. Titanic_RF
Predicts passenger survival on the Titanic using a **Random Forest Classifier**. Includes data preprocessing, feature engineering, and visualizations of feature importance and confusion matrix.  
**Skills:** Python, Pandas, NumPy, scikit-learn, Matplotlib

### 2. Wine_RF
Predicts wine quality scores using **Random Forest Regressor**. Covers train-test splitting, model evaluation using MSE, and feature importance visualization.  
**Skills:** Python, Pandas, NumPy, scikit-learn, Matplotlib

### 3. Customer_Churn_RF
Predicts customer churn in a telecom dataset using **Random Forest Classifier**. Includes data cleaning, categorical encoding, evaluation, and key feature analysis.  
**Skills:** Python, Pandas, NumPy, scikit-learn, Matplotlib

### 4. MNIST_RF
Classifies handwritten digits from the MNIST dataset using **Random Forest Classifier**. Demonstrates image data handling, model training, evaluation, and prediction visualization.  
**Skills:** Python, scikit-learn, NumPy, Matplotlib

### 5. RandomForest_FromScratch
Implements a **Random Forest algorithm from scratch** with NumPy, including decision stumps, bagging, and prediction aggregation on the Iris dataset.  
**Skills:** Python, NumPy, Algorithm Implementation, Machine Learning Fundamentals

### 6. Stock_Simulator_NumPy
Simulates stock price movements using **geometric Brownian motion** with NumPy. Visualizes multiple simulated stock paths.  
**Skills:** Python, NumPy, Matplotlib, Financial Modeling

### 7. Matrix_Operations_NumPy
Performs fundamental **matrix operations** (addition, multiplication) and visualizes matrix products with a heatmap.  
**Skills:** Python, NumPy, Matplotlib, Linear Algebra

### 8. Weather_Visualization_Matplotlib
Visualizes weekly weather data including temperature and rainfall using **line and bar charts**.  
**Skills:** Python, Pandas, Matplotlib, Data Visualization

### 9. COVID19_Visualization_Matplotlib
Tracks COVID-19 cases and deaths over a week with **time series visualizations** using line charts and markers.  
**Skills:** Python, Pandas, Matplotlib, Data Visualization

### 10. Image_Processing_NumPy_Matplotlib
Performs **image processing** tasks like grayscale conversion and inversion using NumPy and Matplotlib.  
**Skills:** Python, NumPy, Matplotlib, Image Processing
